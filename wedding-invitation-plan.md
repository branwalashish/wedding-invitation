## 4. Design Direction

- **Mood:** traditional Indian wedding, but modern and minimal
- **Palette:** Ivory/cream background `#FFF8EC`, Maroon `#7A1F2B`, Gold `#C9A24B`, soft Peach `#F6DFC9`, text Charcoal `#2B2B2B`
- **Fonts (Google Fonts, Devanagari-supported):**
  - Headings: *Yatra One* or *Tiro Devanagari Hindi* (matches the card's calligraphic feel)
  - Body: *Hind* or *Noto Sans Devanagari*
  - English accents: *Cormorant Garamond* / *Playfair Display*
- **Ornaments:** thin gold dividers (like the card's floral lines), mandala corners, kalash/Ganesh icon as SVG
- **Motion:** gentle fade-in on scroll, no heavy animation
- **Imagery:** reuse the card's line-art motifs (couple, elephants, dholak) as clean SVG/PNG

---

## 5. Mobile-First & Responsive Rules

- Design for **360–430 px width first**, then scale up for tablet/desktop
- `<meta name="viewport" content="width=device-width, initial-scale=1">`
- Single column on phone; centered max-width (~480–560 px) on desktop so it still looks like a card
- Min tap-target size 44 px; large readable Hindi text (≥ 16 px body)
- Use `dvh` units for full-screen sections (avoids the mobile browser address-bar jump)
- Compress all images (WebP, < 150 KB each); total page under ~1.5 MB excluding music
- Test on: Chrome Android, Safari iOS, and WhatsApp's in-app browser

## 6. Music Plan — "Aaj Sajeya"

### ⚠️ Important: autoplay limitation
Chrome, Safari and WhatsApp's in-app browser **block audio autoplay** until the user taps something. So a truly automatic song on page load is not possible.

**Solution:** the **welcome screen with an "Open Invitation" button**. The tap counts as user interaction, so the music starts right as the invitation opens. It will feel automatic to guests.

### Music controls
- Floating **mute / play** button (bottom corner) always visible
- Loop the song, volume ~60 %
- Pause the audio when the tab goes to the background

### 📁 Where to paste your MP3
```
wedding-invite/
└── assets/
    └── audio/
        └── aaj-sajeya.mp3     ← PASTE YOUR FILE HERE (exact name)
```
- File name must be exactly **`aaj-sajeya.mp3`** (lowercase, hyphen, no spaces)
- Keep size **under ~3–4 MB** (128 kbps MP3, or trim to ~1:30–2:00 min) so it loads fast on mobile data

## 8. WhatsApp Sharing Optimization

When the link is pasted in WhatsApp it should show a pretty preview card:
- Add **Open Graph tags**: `og:title` ("Suruchi weds Vikky — शुभ विवाह 24.11.2026"), `og:description` ("सस्नेह निमंत्रण 🙏"), `og:image` (`og-preview.jpg`), `og:url`
- Preview image: **1200 × 630 px**, under 300 KB
- Use a short, clean URL
- Use an **absolute** image URL (WhatsApp ignores relative paths)
